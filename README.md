# API-Rest-Pizzeria
Creadoras: Maria Celeste Román, Perla Jazmin Marquez, Maria Jose Arevalo

En este proyecto se desarrolló una API REST para la administración de una pizzería, utilizando Flask como framework principal en Python, SQLite como gestor de base de datos y una interfaz web en HTML y JavaScript para facilitar la interacción del usuario. El sistema permite realizar operaciones CRUD (crear, consultar, actualizar y eliminar) sobre las entidades del sistema, además de manejar información en formato JSON mediante endpoints HTTP.

Asimismo, se aplicaron conceptos aprendidos en desarrollo de sistemas y de bases de datos, como el uso de tablas relacionadas, validación de datos, manejo de errores y medidas básicas de seguridad para evitar vulnerabilidades como SQL Injection.

El objetivo principal de este proyecto es mostrar el funcionamiento de una API REST funcional conectada a una base de datos, ofreciendo una solución práctica para la gestión digital del catálogo de productos de una pizzería.
